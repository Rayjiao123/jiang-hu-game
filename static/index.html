说书人 · an agent that builds agents
The Storyteller interviews you and writes the NPC's scroll itself through tool calls, shown under each reply.

    
恩怨 · a connected world
It reads the existing NPCs first, so yours can owe a debt to, train under, or hunt someone another visitor made.

    
水墨 · painted live
The AI paints each portrait as ink-wash vector art while you watch the brushstrokes arrive as code.

    
信任 · NPCs with memory and motives
Each NPC pursues its own goal and decides how far to trust you. Its secret is kept by the game, not the prompt, and is only released once trust is earned.

    
时代 · bound to their world
NPCs only know what a person of their station could know around 1200. Mention a phone or ask for code and they react as a Song-dynasty swordsman would, with a visible ⚙ out_of_world check.
